# Australia Sustainable Development Report & Live Tracker

**Author:** Aditya Narayan Sharma

An interactive policy observatory tracking Australia's progress across all 17 UN Sustainable Development Goals alongside a **Post-2030 Transformation Lab**.

## Features
- **2030 Live Observatory:** Live API integration (World Bank Open API & Open-Meteo), 3-tier Governance Scale switcher (National, State, Local Melbourne & Monash Clayton), Commonwealth Portfolio mapping, and interactive State/Territory drill-downs.
- **Post-2030 Transformation Lab:** Six Transformations Systems Interlinkage Network (with Demand-Side vs. Supply-Side filtering), Doughnut Economics Safe & Just Operating Space ring, Theory of Change Impact vs. Political Feasibility matrix, Domestic vs. Transboundary Spillover comparison, and 1-click Printable Policy Brief export.
