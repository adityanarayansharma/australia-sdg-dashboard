# Australia Sustainable Development Report & Live Tracker (2030 & Post-2030)

Prepared by Aditya.

An interactive, single-file policy observatory tracking Australia's progress across all 17 UN Sustainable Development Goals alongside a **Post-2030 Transformation Lab** aligned with Monash Sustainable Development Institute (MSDI) and UN research frameworks.

## Key Capabilities
- **2030 Live Observatory:** Live API integration (World Bank Open API & Open-Meteo), 3-tier Governance Scale switcher (National, State, Local Melbourne & Monash Clayton), Commonwealth Portfolio mapping, and interactive State/Territory drill-downs.
- **Post-2030 Transformation Lab:** Six Transformations Systems Interlinkage Network (with Demand-Side vs. Supply-Side filtering), Doughnut Economics Safe & Just Operating Space ring, Theory of Change Impact vs. Political Feasibility matrix, Domestic vs. Transboundary Spillover comparison, and 1-click Printable Policy Brief export.

## Deploy on GitHub Pages
1. Upload `index.html` and `README.md` to a public GitHub repository.
2. Go to **Settings -> Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose `main` and `/ (root)`, and click **Save**.
